# Frontend — pendiente de diagnóstico

Reconocido como bloque grande aún sin mapear en detalle. Antes de listar tareas específicas, el siguiente paso es hacer el mismo ejercicio de diagnóstico que se hizo con el backend:

- [ ] Inventariar en qué estado real está el frontend en Vercel (qué está desplegado, qué rama, qué funciona y qué no)
- [ ] Revisar manejo de errores y estados de carga en las llamadas a la API
- [ ] Revisar que no haya secretos ni tokens expuestos en el bundle de JS
- [ ] Definir, en una siguiente sesión, el mismo tipo de roadmap por fases que se hizo aquí para el backend

> Este bloque queda deliberadamente abierto — se detalla en una próxima sesión dedicada, después de que Celeste esté respondiendo en producción.
